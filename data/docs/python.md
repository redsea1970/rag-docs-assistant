# Python: основы

## Переменные
В Python переменные создаются при присваивании значения. Тип переменной определяется автоматически.

## Списки
Списки — это упорядоченные коллекции. Пример:
fruits = ["apple", "banana", "cherry"]
Добавить элемент: fruits.append("date"). Получить длину: len(fruits).

## Функции
Функция создаётся с помощью ключевого слова def. Пример:
def greet(name):
    return f"Hello, {name}!"
Вызвать функцию: greet("World"). Параметры могут иметь значения по умолчанию.

## Исключения
Исключения обрабатываются конструкцией try/except. Пример:
try:
    result = 10 / 0
except ZeroDivisionError:
    print("Деление на ноль!")
Блок finally выполнится в любом случае. Можно использовать raise для явного вызова исключения.
